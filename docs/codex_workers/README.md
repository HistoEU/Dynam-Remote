# Codex Worker Prompt Files

These files are ready-to-paste prompts for separate Codex instances after the private GitHub baseline exists. Use one prompt per worktree/branch. Do not give a worker more than one prompt unless the earlier worker has finished and merged.

Recommended launch order:

1. `stabilize-github-migration.txt`
2. `browser-pwa-polish.txt`
3. `display-monitor-accuracy.txt`
4. `host-native-capture-spike.txt`
5. `infra-remote-signaling.txt`
6. `mobile-android-shell.txt`
7. `mobile-ios-shell.txt`
8. `product-billing-store-readiness.txt`

Each prompt repeats the required reading list, branch, owned scope, forbidden scope, acceptance evidence, and final report format so the worker does not have to infer its job from scattered docs.
