Fresh Windows Install - Start Here
==================================

This zip is the current ready-to-run Remote Controller package.
It already includes the app dependencies, portable Node, and the high-quality capture helper.

On a fresh Windows laptop:

1. Unzip this package to the Desktop.

2. Double-click:
   START HERE - Remote Controller.bat

3. If Windows Firewall asks, allow access on private/local networks.

4. On the phone, open the URL printed under:
   Paste this on your phone

5. Enter the PIN shown in the launcher window.

6. On the laptop page, approve the phone.

7. To stop it later, double-click:
   Stop Remote Controller.bat

Important:
- Laptop and phone must be on the same Wi-Fi.
- This does not need an account.
- This is free local Wi-Fi use.
- Mobile data / different Wi-Fi needs Tailscale or another private network setup.
- Node.js is bundled. You should not need to install developer tools first.
